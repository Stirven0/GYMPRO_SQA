# Estructura Temática de Pressman (Capítulos 16 a 20)

Este documento detalla el desglose del índice del libro *"Ingeniería del Software - Un enfoque práctico"* de Roger Pressman (Capítulos 16 al 20) que sirve como base conceptual para estructurar el Plan de Pruebas de **GymPro**.

---

## CAPÍTULO 16: Aseguramiento de la Calidad del Software (ACS / SQA)
*   **16.1 Antecedentes**
*   **16.2 Elementos de ACS:** Estándares, revisiones/auditorías, pruebas, colección/análisis de errores, administración de cambios (configuración), educación, gestión de proveedores, seguridad del software y gestión de riesgos.
*   **16.3 Tareas, Metas y Métricas:**
    *   *Tareas del ACS:* Plan de ACS, revisión de procesos, auditorías de productos de trabajo, control de desviaciones.
    *   *Métricas de Calidad:* Requerimientos, diseño, código y eficacia del control de calidad.
*   **16.5 Aseguramiento Estadístico (SSQA):** Clasificación de errores (Pareto 80/20) y Seis Sigma (DMAIC / DMADV).
*   **16.6 Confiabilidad y Disponibilidad:** Cálculo del TMEF ($TMPF + TMPR$) y porcentaje de disponibilidad.
*   **16.7 Normas de calidad ISO 9000 (9001:2000).**
*   **16.8 El Plan de ACS:** Estructura recomendada por la IEEE.

---

## CAPÍTULO 17: Estrategias de Prueba de Software
*   **17.1 Enfoque Estratégico:** Verificación y validación, organización del testing y criterios de finalización de pruebas.
*   **17.3 Estrategias para Software Convencional:** Pruebas unitarias y pruebas de integración.
*   **17.5 Estrategias para WebApps (Aplicaciones Web).**
*   **17.6 Pruebas de Validación:** Criterios de validación, revisión de configuración y pruebas alfa/beta.
*   **17.7 Pruebas del Sistema:** Pruebas de recuperación, seguridad, esfuerzo (stress), rendimiento y despliegue.
*   **17.8 El Arte de la Depuración (Debugging):** Estrategias y corrección de errores.

---

## CAPÍTULO 18: Prueba de Aplicaciones Convencionales (Técnicas)
*   **18.3 Prueba de Caja Blanca:** Pruebas estructurales.
*   **18.4 Prueba de Ruta Básica:** Grafo de flujo, cálculo de complejidad ciclomática, rutas independientes y casos de prueba.
*   **18.5 Prueba de Estructura de Control:** Pruebas de condición, flujo de datos y bucles.
*   **18.6 Pruebas de Caja Negra:** Partición de equivalencia, análisis de valores límite y pruebas de arreglo ortogonal.
*   **18.8 Entornos Especializados:** Pruebas de interfaces gráficas (GUI), arquitectura cliente-servidor y sistemas en tiempo real.

## CAPÍTULO 20: Prueba de Aplicaciones Web (WebApps)
*   **20.1 Conceptos para WebApps:** Dimensiones de calidad de la WebApp, errores en entornos web y planificación de pruebas.
*   **20.3 Prueba de Contenido y Base de Datos.**
*   **20.4 Prueba de Interfaz de Usuario (UI):** Estrategia de prueba de interfaz, mecanismos de interacción, semántica de la interfaz, pruebas de usabilidad y compatibilidad de entornos.
*   **20.5 Prueba a Nivel de Componentes (Funcionalidad).**
*   **20.6 Prueba de Navegación:** Sintaxis y semántica de navegación.

*   **20.8 Prueba de Seguridad.**
*   **20.9 Prueba de Rendimiento:** Objetivos de rendimiento, pruebas de carga y pruebas de esfuerzo.
